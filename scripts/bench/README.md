# 一键生成新页面 · 对比测试

同一条需求，原型工坊在空白页面里一键生成，和 `reference/` 里 Claude 用同一套页面外壳做的参考页并排比较。

## 需求

1. 设备巡检计划管理页（清楚的需求）：指标卡、筛选、表格、新增/编辑/删除、详情弹窗
2. 园区能耗监测看板：指标卡带涨跌、7 天趋势、楼栋占比、日/周/月排行、导出报表
3. 一句话：「做个碳配额管理页面」

需求原文见对话记录；每条都在新的空白页面、「自动」模式下发出，不追加修改。

## 自动检查

```bash
python3 scripts/bench/check.py <生成的页面.html> <输出目录>
```

会打开页面，把每个菜单页的按钮挨个点一遍：记录报错、点了没反应的按钮、关不掉的弹窗；
新增/编辑会自动填表提交、删除会点确认，看数据有没有真的变；下拉筛选后点查询看行数变没变；
在 1440 / 1280 两种宽度下检查横向溢出并截图。需要 `pip install playwright` 和 Chromium。

注意：已经是当前状态的按钮（比如没有筛选时的「重置」、当前页码、已选中的「日」）会被记成「没反应」，看报告时人工排除。

## 合格线

必须全过：页面不报错 · 需求里每一点都有 · 按钮都有反应、增删改和筛选真的生效、弹窗能开能关 · 两种宽度不溢出。
打分（每项 ≥ 4/5）：演示数据像真的 · 符合设计规范 · 视觉层级与反馈。效率：单页 3 分钟内。
