## 0. 怎么使用本文档

- 本文档中的**数值全部是硬约束**，请照抄，不要"按经验微调"。

* 代码块是**可直接复用的实现**，不是示意。

- 优先级：**硬约束 > 代码块 > 说明文字**。三者冲突时以硬约束为准。

## 4. 左侧菜单（**核心章节**）

### 4.1 定位与共用法则

- 左侧菜单是**全局唯一的主导航**，全站所有模块**共用同一份菜单**，内容不同但菜单完全一致。

* **【必须】菜单只在一个地方定义**（配置数组），由构建流程注入到每个页面文件。禁止在每个页面里手写一份菜单 DOM。

- 菜单**展示全部一级模块与其二级子页**，不做权限裁剪（演示原型阶段）。

### 4.2 两级结构

- **一级项**：模块分组名，可折叠/展开，本身**不可点击跳转**。

* **二级项**：具体子页，点击切换内容区。

* 折叠态 `max-height:0`，展开态 `max-height:360px`（够用即可），过渡 `0.22s ease`。

- 箭头旋转与内容展开**同时进行**，过渡时长一致。

### 4.6 展开状态管理 **【必须】**

- 展开状态**不能只写在 DOM class 上**：一旦重渲染会全部重置，用户体验很差（点开别的分组、换个页又全折叠了）。

* **【必须】把展开状态存在一个会话级对象里**，渲染时读它决定是否加 `.open`。

- 默认规则：**当前所在模块的分组默认展开**，其余默认折叠。

```
```

### 4.7 子页路由 **【必须】用 URL hash**

- 当前子页由 `location.hash` 决定，形如 `#devlist`。

* **【必须】不要用 query string 或自建 history 路由**：hash 在单文件、跨文件、被 iframe 嵌三种场景下都可靠，且天然支持"复制链接直达某个子页"。

- **同模块内点菜单**用纯 hash（`href="#key"`）→ 浏览器不重载页面，靠 `hashchange` 重渲染。

* **跨模块**用 `文件.html#key`（本地）或 `<节点URL>#key`（线上），见 §7。

```
```

- **【必须】首次渲染前先同步一次 hash**，否则带 `#st-template` 的分享链接会停在默认子页。

### 4.8 主内容区随之切换的内容

- 面包屑：`模块总览 / <模块名> / <子页名>`

* 页面 `h1`：**子页名**（不是模块名）—— 菜单已标明模块，标题要告诉用户"现在在哪一页"

- 标题下副文案：模块的一句话说明（同一模块内各子页共用）

* **【必须】不要再叠加一层页签（tab）**：菜单二级项已经是子页切换器，再加页签会造成两套并行的导航、状态互相打架。

### 5.2 **【必须】行高必须靠** **`line-height`** **兜住，****`tr{height}`** **无效**

这是全站样式最容易"看起来写了但没生效"的地方：

- **`tr { height: 36px }`** **只是「最小值」**，单元格内容更高时会被顶破。

* 单元格内容高度 = `padding 上下` + **内容行盒** + `border`。而内容行盒由 **继承的** **`line-height`** 决定 —— 这里 `body` 是 `1.5`，12px 字号的行盒就是 **18px**，于是：
  - 表头 `7+7+18+1 = 33px`（想要 31 ≠ 得到 31）
  * 数据行 `8+8+18+1 = 35px`，若含 20px 高的 inline-block 就是 `8+8+20+1 = 37px`（想要 36 ≠ 得到 36）

**正确做法：显式压低** **`line-height`****，让它小于目标值，由** **`tr{height}`** **兜到目标高度。**

### 5.4 **【必须】列宽合计要写成表格** **`min-width`**

- 若声明列宽合计 **> 容器宽度**，浏览器会**按比例把每一列都压扁**（`table-layout:fixed` 下不会溢出，只会挤压）。表现是"操作列里的按钮被切掉半个"。

* 正确做法：把列宽合计算出来写进 `table` 的 `min-width`，让声明宽度不被违反、超出部分交给 `.tw{overflow-x:auto}` 做**卡片内横向滚动**（页面整体不出现横向滚动条）。

### 6.8 组件使用语义与状态（Agent 生成时必须遵守）

这一节解决“尺寸正确，但组件选错/按钮太多/弹窗用法混乱”的问题。**组件不仅要长得一致，还要在正确场景使用。**

#### 6.8.1 按钮层级

| 类型 | 何时使用 | 约束 |
|---|---|---|
| 主按钮 `.primary` | 当前区域唯一的首要动作，如“新增”“保存”“提交” | **同一个操作区最多 1 个主按钮** |
| 默认按钮 | 次要动作，如“取消”“重置”“返回” | 可与主按钮并列 |
| 文字按钮 `.lnk` | 表格行内操作，如“详情”“编辑” | 不用于页面级主操作 |
| 删除文字按钮 `.lnk.danger` | 表格行内删除入口 | 必须进入自定义确认弹窗，不能直接删除 |
| 危险实心按钮 `.danger-solid` | 删除确认弹窗里的最终确认 | 只用于明确的破坏性动作 |
| 禁用按钮 | 当前条件不满足时不可执行 | 不响应 hover / click |
| Loading 按钮 | 正在保存、提交、删除等异步动作 | 保持原宽度，禁止重复点击 |

**【必须】按钮顺序**：弹窗底部右对齐，次要动作在左，主要动作在右；例如 `取消 / 保存`、`取消 / 删除`。

**【必须】不要在同一按钮组中出现两个主按钮。**

#### 6.8.2 弹窗类型选择

| 场景 | 组件 | 宽度 / 行为 |
|---|---|---|
| 新增 / 编辑表单 | Form Modal | 默认 440px；字段较多时 640px |
| 简短详情 | Detail Modal | 440/640px；底部只保留一个“关闭”按钮 |
| 删除 / 停用 / 清空 | Confirm Modal | 440px；明确说明对象和后果；最终确认按钮使用危险实心样式 |
| 长详情 / 多分区表单 | Drawer | 默认 560px，右侧滑出；正文独立滚动 |
| 轻量结果反馈 | Toast | 不打断操作；2.2s 自动消失 |

**【必须】不要用普通 Form Modal 代替删除确认，也不要用 Toast 代替必须确认的破坏性操作。**

#### 6.8.3 弹窗行为

- Form Modal：右上叉 / 取消 / 遮罩空白 / `Esc` 均表示“放弃本次未提交修改并关闭”。
- Confirm Modal：右上叉 / 取消 / 遮罩空白 / `Esc` 均表示“取消危险操作”；**只有点击右侧危险按钮才执行删除/停用等动作**。
- Detail Modal：底部只显示一个“关闭”按钮，不再同时出现“取消 + 关闭”。
- 打开弹窗后锁定页面背景滚动；关闭后恢复。
- 打开时记录触发按钮；关闭后把焦点还给触发按钮。
- 表单校验失败时不关闭、不清空，焦点移动到第一个错误字段。
- 弹窗正文超高时只滚动 `.modal-bd`，头部和底部保持可见。
- 禁止弹窗套弹窗。需要二次信息时优先在当前弹窗内展开，或关闭后再打开下一个层。

#### 6.8.4 抽屉

- 默认宽 **560px**，最大宽 `92vw`。
- 从右侧滑出，遮罩规则与弹窗一致。
- 适合：详情字段较多、历史记录、配置项较多、需要保留主页面上下文的编辑。
- 不适合：简单确认、单字段新增、强提醒。
- 头部 `padding:16px 20px`，正文 `padding:20px`，底部动作区 `padding:14px 20px`。
- 关闭路径：右上叉 / 取消 / 遮罩 / `Esc`。
- 移动端宽度为 `100vw`。

#### 6.8.5 表单状态

输入控件至少覆盖：`default / hover / focus / filled / disabled / readonly / error`。

- disabled：底色 `--head-bg`，文字 `--text-3`，不可聚焦、不可提交修改。
- readonly：允许复制但不可编辑，底色 `--head-bg`。
- error：边框 `--danger`，下方显示 11px 错误文案；错误文案说明“哪里错 + 怎么改”。
- 帮助文案与错误文案不能同时占位；错误优先。
- 必填项用红色 `*`，不得只靠占位符说明必填。

#### 6.8.6 开关 / 状态切换

- 开关尺寸固定 `34×18`。
- 开关只用于**立即生效的二元状态**，例如启用/停用。
- 若切换会造成明显业务风险，点击后必须进入 Confirm Modal。
- 开关旁必须有文字标签，不能只靠颜色表示开/关。
- disabled 状态降低对比度且不可点击。

#### 6.8.7 Loading / Empty / Error

- 列表首次加载：使用骨架或加载占位，不用空态代替加载态。
- 空态：主文案 + 副文案 + 下一步动作。
- 请求失败：显示错误说明 + “重新加载”动作，不伪装成“暂无数据”。
- 按钮提交中：按钮进入 Loading，禁止重复提交；完成后恢复。
- Toast 用于“已保存 / 已复制 / 操作失败”等轻反馈，不承载需要用户作决定的信息。

### 6.9 组件选择快速决策表

| 用户意图 | 首选组件 |
|---|---|
| 新建 / 编辑少量字段 | 440px Form Modal |
| 新建 / 编辑字段很多 | 640px Form Modal 或 Drawer |
| 查看少量详情 | Detail Modal |
| 查看大量详情 / 历史记录 | Drawer |
| 删除 / 停用 | Confirm Modal |
| 成功 / 失败结果提示 | Toast |
| 行内编辑/删除 | 文字按钮 |
| 页面主动作 | 主按钮 |
| 二元即时状态 | Switch |
| 长列表 | Table + Pagination |
| 无数据 | Empty |
| 请求异常 | Error State |

## 8. 验收清单

生成的页面必须逐条通过：

- 所有颜色取自 §1 Token，**无硬编码新色值**

* 字号严格按 §2 阶梯（常规 12 / 品牌 16 / 卡片标题 14 / 菜单一级 12.5 / 标识符 11.5 / 标签 11）

- 顶栏 56px、左侧菜单 172px、内容内边距 `12px 18px 20px`

* 左侧菜单展示**全部**一级模块与二级子页，各页面菜单**完全一致**

- 菜单折叠用 `max-height` 过渡（**不是 display 切换**）

* 二级项选中态 = 主色字 + 500 字重 + `#EAF1FF` 底 + 左缘 3px 主色竖条

- 展开状态在换页/重渲染后**不丢失**

* 子页切换走 URL hash，且**带 hash 打开能直达对应子页**

- **没有**多余的页签条（导航只由左侧菜单承担）

* 表格 `table-layout:fixed` + `<colgroup>` 显式列宽

- **表头实测 31px、数据行实测 36px**（用 `getBoundingClientRect().height` 量，不靠肉眼）

* 单元格内所有元素 ≤19px；inline-block **未加** `vertical-align:middle`

- 列宽合计已写入表格 `min-width`，**操作列按钮无截断**

* 操作列 `nowrap`，编辑/删除**同一行不换行**

- 控件高 30px 圆角 6px；卡片圆角 8px；弹窗圆角 10px

* 弹窗关闭四路径等价；校验失败不关弹窗、不清空

- 有数据的列表**都有分页条**

* 空态有主副文案 + 下一步动作

- **无僵尸按钮**：每个可点元素都有真实行为或明确的占位反馈

* **无 emoji 图标**；图标统一 `viewBox="0 0 24 24"` + `stroke-width:1.8`

- `prefers-reduced-motion` 下无动画

* 页面**整体无横向滚动条**（宽表格只在卡片内横向滚动）

## 9. 禁止事项

1. **禁止** `alert / confirm` 等原生弹窗——一律用自定义弹窗。

1) **禁止**用 emoji 或图标字体当图标。

1. **禁止**仅靠颜色表达状态（必须有文字/形状冗余）。

1) **禁止**在页面里手写第二份菜单 DOM（菜单必须来自单一配置源）。

1. **禁止**在菜单二级项之外再加一层页签导航。

1) **禁止**用 `display` 切换实现折叠动画。

1. **禁止**依赖 `tr{height}` 控制行高而不写 `line-height`。

1) **禁止**改 `body` 的 `line-height` 而不重新核算 §5.2 的表格行高。

1. **禁止**把绿色/橙色用于按钮或装饰（仅限数据标签）。

1) **禁止**在单元格内使用 `vertical-align:middle` 的 inline-block。
