# 零碳园区 UI Skill 包 v3

这是零碳园区管理平台的 UI Skill 包。

## 文件
- `SKILL.md`：Agent 执行入口与强约束。
- `references/零碳园区_UI规范.md`：完整视觉、布局、组件语义与交互规范。
- `assets/零碳园区_UI组件库.html`：可直接打开的组件库与真实交互示例。

## v3 重点修复
- 增加按钮层级、Loading、禁用和“单操作区最多一个主按钮”规则。
- 将弹窗明确拆分为 Form / Detail / Confirm 三类。
- 增加 Drawer 规范和组件。
- 删除操作不再只 Toast，改为自定义确认弹窗。
- 详情弹窗不再出现“取消 + 关闭”两个同义按钮。
- 分页组件加入可点击反馈，避免僵尸按钮。
- 弹窗加入背景滚动锁定、焦点恢复。
