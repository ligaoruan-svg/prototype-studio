# 原型工坊 · 设计规范

面向产品经理制作可点击、可演示的本地单文件原型。

## 视觉语言

暖白底、克制的强调色、细边框、大留白。不用装饰渐变、堆叠阴影、全大写眉题或无意义编号。

颜色一律引用 tokens 里的 CSS 变量，不写死十六进制：

| 变量 | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#faf9f5` | 页面底色 |
| `--color-surface` | `#ffffff` | 卡片、表格、弹窗 |
| `--color-text` | `#141413` | 正文 |
| `--color-muted` | `#6f6e69` | 次级文字、表头、说明 |
| `--color-border` | `#e5e2d6` | 分隔线、描边 |
| `--color-primary` | `#b8532f` | 主操作、当前选中态 |
| `--color-success` | `#4c7a52` | 成功状态、正向指标 |
| `--color-danger` | `#b42318` | 错误、删除、负向指标 |

强调色只给一屏里最主要的那一个操作，以及当前选中态。次级按钮用描边或纯文字，
不要一屏出现三四个实心主色按钮——强调色用得越省，它越有用。

以上每个颜色，当文字和当白字按钮底都已验证过 ≥4.5:1。另配颜色时要自己核对比度。

## 尺寸

- 字号：桌面 24 / 18 / 14 / 12，手机 20 / 16 / 15 / 12，对应 `--font-title` / `--font-heading` / `--font-body` / `--font-small`
- 间距：4 / 8 / 12 / 16 / 24 / 32，对应 `--space-1` 到 `--space-8`
- 圆角：控件 8、卡片 12、弹窗 16，对应 `--radius-control` / `--radius-card` / `--radius-dialog`
- 行高：正文 1.7，标题 1.4
- 主按钮桌面至少高 36px，手机至少 44px
- 控件可通过键盘操作

留白宁可多给：区块之间用 `--space-8`，卡片内边距不低于 `--space-4`。

## 字体

正文、表格、表单、数据一律系统无衬线字体。
页面主标题可以用衬线体（`'Iowan Old Style', Georgia, 'Songti SC', serif`），但同一页最多用在一处。

## 内容

用真实标签、控件和示例数据实现按钮、筛选、弹窗、页签。示例数据要像真的：
金额带千分位、日期是具体某天、状态有多种取值、列表长度不整齐。
外部服务不在原型范围内，需要时明确标为演示。

## 改动约束（优先级高于以上全部视觉要求）

- 所有新的可编辑和交互元素设置唯一 `data-pid`
- 保留所有现有 region 标记和不相关的 `data-pid`
- 改配色只改 tokens；改某一处只改它所属的 region
- 手动编辑覆盖的样式必须保留
- **导入的旧页面优先保留既有样式，不要为了套用本规范去重构它**。
  只有用户明确要求改视觉时才动它的配色和尺寸；这条压过上面所有规定。

公司设计规范可以整份替换本文件。
