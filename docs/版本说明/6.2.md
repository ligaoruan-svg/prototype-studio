**架构模式（新）**
- 贴一段需求先出「业务梳理」卡：角色、业务对象和字段表、状态流转、规则、范围，拿不准的地方让你选
- 确认后出「页面清单」卡：每个模块有哪些页、什么类型（管理列表 / 我的任务 / 看板 / 统计 / 基础配置），可选页打钩
- 按清单由程序展开整棵页面树：页签、筛选、表格列、按钮（什么状态出现、点完变成什么）、弹窗、详情、明细子表，画完自动检查一遍
- 架构画布：模块 / 菜单页 / 页签 / 全部逐层展开，改了只同步那几处到原型；从原型读回来也更准
- 同步到原型时，列表页、状态流转、演示数据由程序直接生成，AI 只补看板、统计和规则，快很多
- 按梳理自动验收：把每个流转点一遍，没过的可以一键交给 AI 修

**对话（参照 Claude 重做）**
- 回答边写边出；推理模型想的过程也显示出来，想完收成「想了 N 秒」
- 工具一步一行：图标 + 在做什么 + 拿到了什么；改代码那一步直接看到改了哪几行（红绿）
- 回复上面「做了 N 步 · 用时」，点开回看当时每一步；刷新后还在
- AI 跑的时候可以插话，下一步就照着调整；最后一条回复可以「换一个回答」
- 回复按段落、列表、加粗排版；拍板的选项一行一个；报错说清下一步怎么办
- 梳理卡、清单卡确认后收起成一行；长对话只显示最近一段

**生成的原型**
- 新的列表页模板：表格列宽按内容、筛选更紧凑、详情两列排、能填明细子表
- 演示数据按状态走：还没派单的单子没有派单时间、处理说明
- 原型左上角显示画布上的系统名，不再是「示例系统」

**修复**
- 一行写完的需求被当成小改，跳过了梳理
- 同步后画布多出一个以系统名命名的模块
- 表格时间被截成「2026-11-08...」、状态列被操作列压住
