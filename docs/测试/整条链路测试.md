# 整条链路测试：梳理 → 画架构 → 做页面 → 自动验收 → 自动修（用自己的模型跑）

## 开始前

1. 关掉原型工坊，双击 `scripts/启动原型工坊.command` 重新打开（后台改过，旧的服务不认新功能）。
2. 浏览器里按 ⌘⇧R 强制刷新一次。
3. **新建原型，选一套风格（比如「企业蓝」）**。要选风格：页面外壳里才有统一数据层，验收才跑得起来。

## 题目：物业报修（整段复制粘贴）

```
物业报修管理后台（电脑端）
业主在小程序提交报修（分类、描述、照片、预约上门时间）
客服在后台受理、派单给维修工，紧急报修 30 分钟内必须派单
维修工在后台接单、上门、填写处理结果和用料，完工后业主评价
维修产生的材料费、人工费要记录，月底和收费系统对账（收费系统已有）
主管要看工单统计、超时工单、维修工绩效
```

## 按顺序做，对照着看

| # | 做什么 | 看什么（对的样子） |
|---|---|---|
| 1 | 点顶上「架构」，粘贴需求发送 | 出「业务梳理」卡片：角色、业务对象、状态流转（派单：待派单→处理中 这种）合理 |
| 2 | 点「按这个画架构」 | 画出页面树，回复最后有「检查：…」 |
| 3 | 点画布底部「同步到原型」，发送 | AI 开始做页面（会比较久，几分钟到十几分钟都正常）。做完后结果卡下面有两行：自检结果、**「按梳理验收：N/M 条流转走通」**；有没过的会自动再修一轮 |
| 4 | 修完后回到架构画布，点顶上的 **验收原型**（剪贴板带勾的图标） | 画布上列出每条流转 ✓ / ！，没过的写了原因；有没过的就点「交给 AI 修」，修完再点一次验收 |
| 5 | 自己在预览里点一遍：找一条「待派单」的工单点「派单」 | 状态变成处理中、「派单」按钮消失；切到首页 / 统计页，数字跟着变；切回来状态还在（没被重置） |
