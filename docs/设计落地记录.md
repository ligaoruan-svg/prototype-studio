# 原型工坊 · 本次设计落地

依据：用户提供的《原型工坊-设计思路.md》，以及现有 Prototype Agent 项目。

## 设计决策

- 面向产品经理的本地原型工作台。左侧对话和项目页面，中间预览，右侧确定性的属性编辑。
- 延续系统中文字体、浅色工作区、细边框；采用文档给出的青绿色主色。控件紧凑，不使用装饰性卡片或渐变。
- 沿用 Python / FastAPI + Vue，避免为换技术栈迁移现有项目。前端统一由 Vue 构建，消除源码和手写 dist 两套实现。
- 新原型有 tokens、region 和 data-pid；导入的旧原型保持原文件布局，仅在需要时追加局部样式。动态 DOM 无可靠源码位置时交给 AI。
- 定位依赖原始源码偏移；BeautifulSoup 仅用于查询，不再重新序列化整页。唯一命中和版本冲突由程序检查。
- 手动编辑与 AI 修改先产生候选结果，静态校验和独立 iframe 运行检查通过后提交。手调有独立连续撤销记录，AI 与恢复有版本快照。
- 模型地址、模型名称和密钥在本地服务配置；浏览器不持久化密钥。只展示 API 返回的 token 数，不虚构费用。

## 工作区结构

顶栏：项目切换 / 新建 / 导入 / 历史 / 导出 / 模型设置。

左栏：对话、页面标签；已选目标和标注；输入与执行状态。

中栏：预览 / 源码；桌面 / 平板 / 手机；交互 / 点选；画布；保存、校验状态。

右栏：选中元素；文字；token 颜色；字号、圆角、内边距；显隐；撤销与交给 AI；项目设计变量。

窄屏：对话和属性折叠为显式可打开的抽屉，画布保持可用。

## 状态与验收

导入或新建 → 预览 → 点选 → 属性即时预览 → 本地校验 → 运行检查 → 保存。

对话修改 → 读取相关源码 → 精确补丁 → 本地校验 → 运行检查 → 新版本；失败保留现有版本与用户输入，可重试。

验证：只改目标外的源码字节保持一致；重复命中拒绝；错误脚本拒绝；动态元素不给错误位置写入；撤销可恢复原文；点选不触发原交互；窄屏和键盘操作可用。
